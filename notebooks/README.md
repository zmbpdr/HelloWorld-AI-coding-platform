# ML 实验室模板

内置合成数据，开箱即用。无需外部数据集。

## 使用流程
1. 复制模板到 student-work/
2. 运行内置合成数据 → 查看效果
3. 可选：上传自己的 CSV 数据替换
4. 训练完成 → 下载 outputs/ 里的模型和图表

## 模板列表
- 01_neural_network.ipynb — 神经网络基础 (XOR 问题)
- 02_cnn.ipynb — 卷积神经网络 (MNIST 合成)
- 03_rnn.ipynb — 循环神经网络 (文本生成)
- 04_nlp.ipynb — 自然语言处理 (情感分析)
- 05_recommendation.ipynb — 推荐系统 (协同过滤)
